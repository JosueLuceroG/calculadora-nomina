REQUISITOS DE ESTA CANDIDATURA
- Windows 11 x64 como plataforma validada; cuenta de usuario estándar.
- Microsoft Edge WebView2 Evergreen Runtime. El instalador incluye solo su
  bootstrapper: si falta el runtime, NECESITA INTERNET para descargarlo.
- Pantalla que permita una ventana de al menos 900 x 600 unidades lógicas.
- No requiere OpenCode, Node, Rust ni servidor de desarrollo para usarla.
- Windows 10 y una máquina limpia sin WebView2 no se validaron en este corte.

INSTALACIÓN Y ACTUALIZACIÓN
1. Cierra la calculadora. Comprueba el SHA-256 del archivo.
2. Abre el instalador y sigue el asistente para el usuario actual.
3. Para actualizar 0.1.0, conserva usuario y carpeta de instalación. No borres
   los datos de aplicación. Se probó la actualización real a 0.1.1-rc.1.
4. Abre Calculadora de Nómina desde Inicio. Windows puede mostrar editor
   desconocido/SmartScreen porque este archivo NO está firmado.
5. No vuelvas a instalar 0.1.0 después de guardar cálculos con la candidata:
   el lector antiguo no conoce el nuevo productor documental.
