CALCULADORA DE NÓMINA
Versión 0.1.1-rc.1 para Windows 11 de 64 bits
Instalador offline

Gracias por probar la aplicación. Este archivo corresponde al instalador que
incluye WebView2, pensado para equipos sin internet.

ARCHIVO
CalculadoraNomina_0.1.1-rc.1_offline_x64-setup.exe
Tamaño: 222,910,288 bytes (212.58 MiB)
SHA-256:
6e049470e1dc1cfd2814f1eeb81f9143e7a32c941db5b9897dc9793c3ff8fbbe

QUÉ INCLUYE
La aplicación y el instalador offline de Microsoft Edge WebView2. No necesitas
internet para instalar ni para calcular. La plataforma validada es Windows 11
de 64 bits. Windows 10 no se validó en esta versión.

CÓMO INSTALAR
1. Comprueba el SHA-256 del archivo (opcional, pero recomendable).
   En PowerShell:
   Get-FileHash -LiteralPath ".\CalculadoraNomina_0.1.1-rc.1_offline_x64-setup.exe" -Algorithm SHA256
   El resultado debe coincidir con el valor de arriba.
2. Cierra la calculadora si ya la tienes abierta.
3. Abre el instalador y sigue el asistente.
4. Abre "Calculadora de Nómina" desde el menú Inicio.

SI WINDOWS MUESTRA UN AVISO
El instalador todavía no tiene firma digital. Es posible que Windows muestre
"Windows protegió tu PC" o "editor desconocido". Puedes elegir "Más información"
y después "Ejecutar de todas formas". No desactives SmartScreen.

TUS DATOS
El historial y las preferencias se guardan en:
%LOCALAPPDATA%\mx.calculadoranomina.desktop\payroll.sqlite3

La base local no está cifrada. El guardado automático empieza desactivado en un
perfil nuevo. Los PDF se guardan en la carpeta que elijas. Si desinstalas y
quieres conservar el historial, deja sin marcar "Eliminar los datos de la
aplicación".

ALCANCE
La aplicación estima nómina de 2026 para salario ordinario fijo, totalmente
gravado, en la zona general, con periodos de 7, 15 o 30 días.

No es CFDI, no sustituye SUA o CONTPAQi y no es un cálculo fiscal certificado.
No cubre ingresos variables, exentos, incidencias, otros patrones, IMSS manual,
pago fiscal diario independiente ni el ejercicio 2027. "IMSS No" no significa
una exención legal.

Esta es una versión de prueba. La revisión fiscal y la instalación en un Windows
limpio siguen pendientes. No uses el resultado como cálculo oficial.
